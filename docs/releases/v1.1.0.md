# v1.1.0: whiptail UI, Docker CI matrix, agent skills, and secure /tmp hardening

### Summary

This release makes **whiptail** the default interactive installer UI (with automatic classic text
fallback), adds portable package/mail helpers, and ships a Dockerized lint + coverage + distro-matrix
CI pipeline for Pi-capable OS families. It expands the agent/skills pack for contributors and coding
agents, and closes local privilege-escalation TOCTOU races on predictable `/tmp` paths in the Samsung
firmware updater and the uninstaller.

### What Changed

#### 1. Installer UI and Dependencies

- Interactive installer defaults to whiptail dialogs (checklist, menus, input/password boxes).
- Fresh whiptail install offers **Continue/Cancel** and **Download/Cancel** so setup can be aborted
  before scripts are written; Esc on email/checklist also aborts (no text-UI fallback on Cancel).
- Interactive UI shows the suite version from root `VERSION` from the start (header / welcome / menu).
- Classic text UI remains the automatic fallback when whiptail cannot be installed or cannot run.
- `check_dependencies` installs curl, mail-transport, and whiptail (or OS-family equivalents).
- `install.sh --update` stays non-interactive and cron-safe for self-update.
- Pi vs non-Pi behavior preserved (skip Pi-only tasks on non-Pi; firmware updates still available).

#### 4. Secure Temporary Files (TOCTOU)

- Samsung ISO download no longer uses predictable `/tmp/samsung_fw.iso`; uses `mktemp` + mode `600`.
- Uninstaller crontab rewrite no longer uses predictable `/tmp/root_cron.*` / `/tmp/user_cron.*`;
  uses `mktemp` + mode `600` for bak/new files before `crontab` load.
- Closes local root RCE / crontab-injection races on multi-user hosts with cron-scheduled updates.

#### 7. Version Single Source of Truth

- Added root `VERSION` file (`v1.1.0`) as the suite version SSOT.
- `install.sh` writes `$INSTALL_DIR/.version` from local `VERSION` or `$RAW_URL/VERSION` (no longer from Releases API at install time).
- `update_self.sh` stages tagged `VERSION` next to `install.sh` before `--update`.
- Component tests use isolated `/tmp` `INSTALL_DIR` so parallel matrix containers do not race on a repo bind-mount path.
- Rocky 9 test image installs `curl` with `dnf --allowerasing` to replace `curl-minimal`.
- Cron PATH seeding moved into `lib/os_pkg.sh` and skips when `MOCK_DIR` is set so Fedora's real `7z` cannot defeat Samsung path-hiding tests.

- No intentional breaking changes to installed script names or cron entry formats.
