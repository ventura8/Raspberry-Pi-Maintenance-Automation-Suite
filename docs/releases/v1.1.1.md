# v1.1.1: fix OS-update email leak, harden self-update, drop gettext UI

### Summary

This patch release stops OS update reports from using a hardcoded developer inbox, hardens
`download_scripts` / self-update so installed scripts keep the user's configured recipient across
`--update`, removes GNU gettext localization (English-only UI via `lib/ui_msg.sh`), and syncs
agent/docs invariants for the new behavior.

### What Changed

#### 1. OS update email recipient (security)

- `scripts/update_pi_os.sh` ships `RECIPIENT_EMAIL="your_email@gmail.com"` (no real address).
- `download_scripts` rewrites `RECIPIENT_EMAIL="..."` to the configured ssmtp/msmtp user (same
  pattern as `save_email_configuration`), so fresh install and `--update` cannot restore a
  third-party inbox.
- Regression tests: source placeholder invariant + download injection rewrite.

Files:

- `scripts/update_pi_os.sh`
- `install.sh`
- `tests/unit_tests.bats`
- `tests/component_tests.bats`

#### 2. Self-update and `--update` hardening

- `update_self.sh` stages tagged `install.sh`, `VERSION`, and `lib/` in a `mktemp` tree and runs
  `bash <stage>/install.sh --update` (no `$INSTALL_DIR/../install.sh`, no stdin pipe).
- `--update` can source `$INSTALL_DIR/lib` when the installer tree has no sibling `lib/`.
- Suite crontab lines use `>/dev/null 2>&1`; `--update` rewrites existing lines via
  `quiet_suite_cron_jobs` (preserving `@daily`-style macros).
- Script downloads use atomic same-dir `mktemp` + `mv`.
- Fresh `curl|bash` bootstraps `os_pkg.sh` / `mail_send.sh` / `ui_msg.sh` from `$RAW_URL/lib/` when
  no local `lib/` is present.

Files:

- `scripts/update_self.sh`
- `install.sh`
- `tests/component_tests_self_update.bats`
- `tests/install_extended.bats`

#### 3. Remove gettext localization

- Replaced `lib/i18n.sh` / catalogs with English-only [`lib/ui_msg.sh`](../../lib/ui_msg.sh).
- Deleted `po/`, `scripts/i18n/`, PO/`msgfmt` lint gates, and `tests/component_tests_i18n.bats`.
- Installer no longer installs gettext or compiles locale catalogs.

Files:

- `lib/ui_msg.sh` (new)
- `lib/i18n.sh`, `lib/i18n_soft.sh` (removed)
- `po/*`, `scripts/i18n/*` (removed)
- `tests/lint.sh`, `tests/run_suite.sh`
- Docker lint/test images (no gettext package)

#### 4. Docs and agent skills

- Documented email-placeholder + `download_scripts` rewrite invariants.
- Removed “Always Update Translations” / UI Localization catalog workflows from AGENTS and skills.
- `prepare-release` skill requires amending **both** commit title and body to match the release.

Files:

- `AGENTS.md`, `Instructions.md`, `README.md`, `docs/*`
- `.agents/skills/**`, `.github/**`, `.agent/instructions.md`

### Validation

- `./scripts/build-and-test.sh --full` (Docker lint, coverage ≥ 90%, complexity ≤ 15, distro matrix
  compat + e2e).

### Breaking Changes

- Localized UI catalogs are removed; installer and maintenance messages are English-only.
- Existing installs that already had the hardcoded recipient in `update_pi_os.sh` are corrected on
  the next `install.sh --update` / self-update once this release is published.

### Notes

- Suite version SSOT remains root `VERSION` (`v1.1.1`). GitHub release tags must match exactly.
